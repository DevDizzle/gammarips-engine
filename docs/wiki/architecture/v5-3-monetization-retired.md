# V5.3-era WhatsApp/tiered-pricing monetization plan is retired

The 2026-04-20 plan monetized via a paid WhatsApp push of the curated daily pick with tiered
pricing (Free / Starter $19 / Pro $39 / Pro Annual, founder $29 lock) and an MCP chat agent
as the moat. This is **retired**: the current north-star is human-UI-100%-free (SEO funnel)
with monetization ONLY on MCP access for bring-your-own-agent traders ($39/mo), the WhatsApp
tier was killed, and the daily pick left every public surface ([[public-tracks-pool-not-pick]]).

Kept as a retired note so the old pricing/WhatsApp framing is recognized as superseded. The
durable engineering artifacts it spawned (MCP hardening, `todays_pick` doc, cohort_stats
surface) live on in their own notes.
